## Certifications Earned

### 1. Responsive Web Design (freeCodeCamp)
**Completed:** July–August 2025

Projects shipped:
- Survey Form — accessible form design, ARIA labels, validation
- Tribute Page — semantic HTML, document structure, typography
- Technical Documentation Page — multi-section layout, navigation
- Product Landing Page — flexbox, responsive grid, CTA design
- Personal Portfolio Webpage — first deployed personal project

**What this built:** The eye for layout, typography, and accessibility that shows in every production app.

### 2. JavaScript Algorithms & Data Structures (freeCodeCamp)
**Completed:** August 2025

Projects shipped:
- Palindrome Checker — string manipulation, edge case thinking
- Roman Numeral Converter — algorithmic thinking, lookup tables
- Caesar Cipher — character encoding, modular arithmetic
- Telephone Number Validator — regex patterns, input validation
- Cash Register — floating point precision, state management

**What this built:** The algorithmic thinking that now runs five AI agents across AdminOS. The regex patterns now validating WhatsApp phone numbers. The floating point precision now handling ZAR cent arithmetic.

### 3. Front End Development Libraries (freeCodeCamp)
**Completed:** September 2025

Projects shipped:
- Random Quote Machine — React state, API calls, component design
- Markdown Previewer — controlled components, string transformation
- Drum Machine — event handling, audio API, visual feedback
- JavaScript Calculator — complex state, operator precedence
- Pomodoro Clock — timers, intervals, pause/resume logic

**What this built:** The React component model that now powers six production applications. The state management patterns that now handle student budgets, stokvel contributions, and business dashboards.
